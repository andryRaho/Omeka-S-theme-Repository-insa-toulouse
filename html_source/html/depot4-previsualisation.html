Comment déposer un document ?

Télécharger l’aide

  • Cliquez sur « DÉPOSER UN DOCUMENT »
  • Identifiez-vous avec vos identifiants ENT
  • Sélectionnez le type de document « Thèse »
  • Saisissez les informations correspondant à votre dépôt dans l’onglet Détails
  • Téléchargez le(s) fichier(s) correspondant de votre thèse
  • Choisissez les mots sujets correspondant à votre sujet de recherche dans l’onglet Sujet
  • Pré-visualisez et validez votre dépôt
